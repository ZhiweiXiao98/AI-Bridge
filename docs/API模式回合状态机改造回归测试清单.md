# API 回合与工具调用回归清单

> 复核日期：2026-09-26。适用范围包括文本流式、Markdown 工具、OpenAI-compatible 原生工具、客户端投影和会话持久化。勾选项须附本次运行证据。

## 准备

- [ ] 记录代码版本、客户端/服务端运行方式、Provider、模型、Profile 和工具协议。
- [ ] 确认测试会话、项目路径与允许执行的工具。
- [ ] 打开日志与上下文工作台，确认可以读取请求快照。
- [ ] 根据[测试说明](../tests/README.md)运行受影响模块的自动化测试。

## 文本与流式

- [ ] 普通请求持续显示正文，结束后最终消息与持久化历史一致。
- [ ] 支持 thinking 的普通流式请求正确显示并保存思考 segment。
- [ ] 首次请求、空会话、重新加载和重复发送具有可读状态。
- [ ] 切换会话后，正在处理的事件仍对应正确的目标会话。

## 工具闭环

- [ ] Markdown 工具请求经过解析、执行、反馈和后续回复完整收口。
- [ ] OpenAI-compatible 同步原生工具请求返回结构化工具结果及最终答复。
- [ ] OpenAI-compatible 流式原生工具请求正确累积参数、执行工具并继续生成。
- [ ] 多工具与连续多轮调用中，`tool_call_id`、结果和 UI 展示保持对应。
- [ ] 工具错误、参数错误和调用轮数限制产生明确反馈。
- [ ] Profile 的协议选择、能力探测与 fallback 行为符合[工具协议](API模式原生工具调用与提示词分流计划.md)。

## 状态与持久化

- [ ] 流结束、工具执行和回合完成分别更新对应状态。
- [ ] 工具运行期间界面状态清楚，结束后临时气泡与正式历史一致。
- [ ] 请求快照包含对应回合、工具协议、候选与反馈信息。
- [ ] 重建会话存储后，历史、thinking、工具反馈和最近快照可读取。
- [ ] 项目切换、会话切换和模式切换后，内容及目标路径一致。

## 异常与恢复

- [ ] 取消、超时、断网、限流及 Provider 参数错误产生可识别状态。
- [ ] fallback 发生时没有重复输出或重复执行工具。
- [ ] 重复事件与陈旧事件的处理保持消息和工具结果一致。
- [ ] 服务重新连接后可恢复目标会话与最终状态。

## 当前待开发与专门验收

Gemini 原生工具和 native tools 多轮 reasoning 回放见[当前项目状态](当前项目状态.md)。实现后增加对应 Provider 场景与请求证据。

每次记录运行日期、环境、步骤、预期、实际结果及日志位置。自动化通过范围与真实 Provider 验收分别记录到 [AI_JOURNAL.md](../AI_JOURNAL.md)。

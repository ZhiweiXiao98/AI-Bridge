
# 任务委托说明书

## 项目目标
开发一个纯 Python 实现、无 AI 依赖、不修改原始代码、无需特殊注释的工具模块，功能：
将普通 Python 源码，自动转换为「中文结构化伪代码视图」，给不懂英文、不懂编程的小白看懂代码逻辑，长期可查阅、可追溯，用于降低认知负债。

## 核心规则（必须严格遵守）
1. 不修改原始 `.py` 文件任何内容，只做读取与解析。
2. 不调用任何大模型、不联网、不使用翻译 API，全程本地静态分析。
3. 仅使用 Python 内置 `ast` 模块做语法树解析，无第三方 heavy 依赖。
4. 内置固定编程关键字中英对照表与通用编程词汇英汉词典，做确定性翻译。
5. 输出与源码结构一一对应的中文伪代码，保持结构和行号对应。

## 必须实现的翻译内容

| for        | 遍历     |
| while      | 循环     |
| return     | 返回     |
| class      | 类       |
| import     | 导入     |
| from...import | 从...导入 |
| try        | 尝试     |
| except     | 捕获异常 |
| finally    | 最终执行 |
| break      | 跳出     |
| continue   | 继续     |

### （2）通用编程单词 → 中文（内置词典，可扩展）
| 英文词汇 | 中文翻译 |
|----------|----------|

| set      | 设置     |
| save     | 保存     |
| close    | 关闭     |

**补充规则**：
- 支持驼峰、下划线自动拆分翻译：load_config → 加载配置；create_default_config → 创建默认配置；connect_chroma → 连接向量库
- 支持文件名称/路径翻译："config.toml" → "配置文件.配置文件格式"

## 输出格式要求（强制）
1. 保留原代码层级缩进，结构完全一致。
2. 保留：函数定义、判断、循环、调用、返回结构。
3. 不保留复杂表达式细节，只保留业务可读的动作。
4. 输出为纯文本，适合在 Qt 界面文本框直接展示。

## 示例输入输出
### 【示例输入 - 原始Python代码】
（纯文本格式，与实际源码完全一致）
def load_config():
    if not os.path.exists("config.toml"):
        create_default_config()

### 【示例输出 - 中文伪代码】
（严格对齐缩进，纯文本展示，无任何代码块标记）
函数 加载配置():
    如果 文件不存在("配置文件.配置文件格式"):
        创建默认配置()

## 额外约束（必须满足）
- 支持：函数定义、函数调用、if/else/elif、for/while、基础缩进结构。
- 不做运行、不做执行、不做动态逻辑，纯静态展示。
- 输出目标：小白能看懂流程，不需要懂 Python 英文语法。
- 代码结构稳定、可被集成到 PySide6 桌面客户端中。
- 提供单一入口函数，输入源码字符串/文件路径，输出中文伪代码字符串。

## 交付物要求
1. 完整可运行的单个 Python 模块（或少量文件）。
2. 内置关键字映射 + 通用词汇词典（可扩展）。
3. 注释清晰，方便后续扩展更多词汇与语法。
4. 附带 1~2 个测试示例，演示输入输出效果。

我们不需要两个真的 AI，我们只需要 “分身术”。利用网页端支持多会话（Session）的特性，我们在浏览器中维护两个并行的会话，通过脚本自动切换来实现“双脑”。

成本归零：完全复用您已买断的网页端会员，无需申请任何 API Key，无需担心额度耗尽。
上下文隔离：

侧车会话：专门用来“倒垃圾”（巨大的报错堆栈、重复的尝试代码）。哪怕它因为上下文过长变笨了，直接删掉新建一个即可，完全不心疼。
单人效率最大化：
作为独立开发者，您不需要真正的“并发”（即您在聊天的同时后台在修修补补）。
您需要的是 “自动化的串行”：写完代码 -> 自动跑测试 -> 报错了 -> 自动切到侧车号去问 -> 修好了 -> 切回来告诉您。

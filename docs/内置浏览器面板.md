# 内置浏览器面板

## 目标

内置浏览器面板用于在 AI Bridge 桌面端内部渲染 HTML 页面、本地可视化产物、WebGL/Three.js/Cesium 数字孪生画面，以及后续由 AI 生成的可交互页面。

面板遵循现有 `DockablePanel` + `PanelManager` 架构，属于一等内置面板，自动参与：

- 停靠、浮动、隐藏与最小化。
- 面板菜单开关。
- 工作区布局保存与恢复。
- 统一日志提示。

## 技术依据

Qt 官方文档说明，`QWebEngineView` 是 Qt WebEngine 的主要网页显示控件，可用于显示网页文档；Qt for Python 也提供同名 PySide6 绑定。`QWebEngineProfile` 负责 Profile、缓存、Cookie 和持久存储；`QWebEngineSettings` 负责 JavaScript、WebGL、未知 URL Scheme 等网页能力设置。

参考资料：

- [QWebEngineView - Qt for Python](https://doc.qt.io/qtforpython-6/PySide6/QtWebEngineWidgets/QWebEngineView.html)
- [QWebEngineProfile - Qt for Python](https://doc.qt.io/qtforpython-6/PySide6/QtWebEngineCore/QWebEngineProfile.html)
- [QWebEngineSettings - Qt for Python](https://doc.qt.io/qtforpython-6/PySide6/QtWebEngineCore/QWebEngineSettings.html)

## 文件

- `app/ui/components/panels/browser_panel.py`
  - `BrowserPanel`：主面板。
  - `load_webengine_runtime()`：懒加载 Qt WebEngine，避免缺运行库时主程序启动失败。
  - `normalize_browser_url()`：统一处理 URL、域名、本地文件路径。
- `app/ui/components/panels/__init__.py`
  - 导出 `BrowserPanel`。
- `app/ui/main_window.py`
  - 在 `create_devops_panels()` 中注册 `embedded_browser` 面板。
- `requirements.txt` / `requirements_client.txt`
  - 声明 `PySide6-Addons`，确保 Qt WebEngine 组件随桌面客户端环境安装。

## 能力

- 地址栏打开 `http://`、`https://`、`file://`、`about:`、`data:` URL。
- 域名自动补全为 `https://...`。
- 本地路径自动转换为 `file://`。
- 打开本地 HTML 文件。
- 直接渲染 HTML 字符串。
- Qt WebEngine 可用时启用 JavaScript、本地资源访问、WebGL、2D Canvas 加速。
- 提供持久 Profile，路径位于 `.config/embedded_browser/`：
  - `cache/`
  - `storage/`
  - `downloads/`
- WebEngine 不可用时自动降级为 `QTextBrowser` 轻量 HTML 预览，不影响主程序启动。

## AI 调用接口

其他 UI 或 Agent 逻辑可以通过主窗口上的面板实例调用：

```python
window.embedded_browser_panel.load_url("https://example.com")
window.embedded_browser_panel.load_file(r"C:\Data-Bridge\docs\导出HTML\index.html")
window.embedded_browser_panel.render_html("<html><body><h1>Hello</h1></body></html>")
window.embedded_browser_panel.run_javascript("document.title")
```

`run_javascript()` 在轻量预览模式下会返回 `False`，调用方应据此决定是否提示用户补齐 WebEngine 环境。

## 环境说明

如果启动时日志出现“内置浏览器已启用轻量 HTML 预览降级模式”，说明当前 Python 环境无法加载 `PySide6.QtWebEngineWidgets`。通常需要重新安装或修复桌面端依赖：

```powershell
pip install -r requirements.txt
```

在 Windows 上还应确认 Microsoft Visual C++ Runtime 与 Qt WebEngine 依赖 DLL 完整可用。

## 2026-05-26 适配增强

- 支持多标签页：每个标签页拥有独立视图与独立 WebEngine Profile。
- 支持设备模式：当前标签页可在 `电脑网页` 与 `手机网页` 间切换。
- 电脑网页模式使用桌面 User-Agent，并以 1280px 作为目标布局宽度自动缩放，适合右侧窄停靠面板中查看桌面版网页。
- 手机网页模式使用移动端 User-Agent，并以 390px 作为目标布局宽度自动缩放，让网页自身识别并渲染手机网页版。
- 客户端窗口始终是桌面客户端；所谓手机/电脑模式只作用于网页收到的 User-Agent 与布局宽度，不改变 AI Bridge 桌面 UI。
- 该面板可作为未来 Chrome 调试浏览器替代方案的渲染基础。完整替代还需要新增 DOM/JS 抓取适配层，对接现有 `app.core.driver` / worker 浏览器源协议。

## 2026-05-26 前台活跃策略

- 内置 WebEngine 标签会注入前台可见性脚本，让 AI 网页看到 `document.hidden === false`、`document.visibilityState === "visible"`、`document.hasFocus() === true`。
- 面板隐藏时不通过额外滚动来强制渲染；后台运行的目标是让网页认为自己仍处于前台活动页面，从而减少 AI 网页因失焦、隐藏或 Page Visibility API 判断导致的懒渲染。
- 对接浏览器 Profile 时新增 `browser_source` 概念：默认 `external_chrome` 保持原外接 Chrome 调试端口链路；`embedded_qt` 作为内置浏览器源入口，后续由 UI 线程 WebEngine 执行器承接真实 DOM/JS 调用。

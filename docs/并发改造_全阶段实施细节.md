## 三、线程安全分析

### 3.1 改后线程模型

```text
主线程 (QThread.run)  → _run_browser_loop()  [浏览器轮询]
子线程 (threading)    → _run_api_loop()       [API 事件循环]
线程池 (executor)     → 工具执行、后台任务
```

### 3.2 共享属性风险清单

| 属性 | Browser 线程 | API 线程 | 风险 | 保护 |
|------|-------------|----------|------|------|
| `self.ui_focus` | 读 | 读/写 | 低（原子赋值） | 无需锁 |
| `self._browser_active` | 读 | 不碰 | 无 | — |
| `self._api_active` | 不碰 | 读/写 | 无 | — |
| `self.api_source` | 不碰 | 读/写 | 无 | — |
| `self.connector` | 读/写 | 不碰 | 无 | — |
| `self._round_sm` | 读/写 | 不碰 | 无 | — |
| `self.scheduler` | 读/写 | 读 | 低 | 内部已有锁 |
| `self.file_service` | 读/写 | 读/写 | ⚠️ 中 | 阶段四加文件锁 |
| `self.tool_router` | 读/写 | 读/写 | ⚠️ 中 | executor 串行保证 |
| Qt Signals (emit) | emit | emit | 无 | Qt 线程安全 |

### 3.3 结论

**阶段一不需要额外加锁。** 浏览器和 API 操作的属性几乎完全不重叠，Qt Signal emit 线程安全，scheduler 内部有锁。文件操作冲突留到阶段四。

## 四、API 循环启动时机

### 4.1 方案：懒启动 + 常驻

```text
启动时序：
  1. WorkerThread.run() 被调用
  2. 立即创建 API 线程（daemon），进入 idle 等待
  3. 主线程启动浏览器循环
  4. API 线程循环检测 self._api_active
     - False → sleep(1.0)，不消耗资源
     - True  → 正常工作
  5. 用户首次切到 API 模式时：
     → switch_mode("api") 触发 _init_api_source()
     → self._api_active = True
     → API 循环开始处理消息
```

### 4.2 启动时序图

```text
时间 →

[程序启动]
    │
    ▼
WorkerThread.run()
    │
    ├─── 创建 API 线程 (daemon, idle)
    │         │
    │         ▼
    │    _run_api_loop()
    │         ├── _api_active=False → sleep(1.0) 循环
    │         │
    │         │   ... 用户点击 API 模式 ...
    │         │
    │         ├── switch_mode("api") → _api_active=True
    │         ├── _init_api_source()
    │         ├── 正常工作：检查 pending_text、处理流式
    │         ▼
    │
    ▼
_run_browser_loop()  [主线程，始终运行]
    ├── _connect_browser()
    ├── while self.running:
    │     ├── _browser_scan_queues()
    │     ├── _browser_detect_state()
    │     ├── _browser_process_messages()
    │     └── sleep(0.3)
    │
    │   用户切焦点到 API → 浏览器循环不受影响
    │   用户切焦点回来 → snapshot 推送最新数据
    ▼
```

```python
def switch_mode(self, mode: str, **kwargs):
    """切换 UI 焦点。不再互斥停止另一方。"""
    if mode == self.ui_focus:
        return
    old_focus = self.ui_focus
    self.ui_focus = mode
    self.safe_emit_status(f"🔄 焦点切换: {old_focus} → {mode}")
    self.mode_changed_signal.emit(mode)

    if mode == "api":
        # 首次切到 API：激活循环
        if not self._api_active:
            self._init_api_source()
            if self.api_source:
                self._api_active = True
        # 推送 API 数据到 UI
        if self.api_source:
            convs = self.api_source.get_conversations()
            self.sessions_signal.emit(convs if convs else [])
            if hasattr(self.api_source, "has_active_conversation") and self.api_source.has_active_conversation():
                msgs = self.api_source.get_history_as_messages()
                self.messages_signal.emit(msgs if msgs else [])
                status = self.api_source.get_context_status()
                self.context_status_signal.emit(status)
    else:
        # 切回浏览器：推送浏览器最新快照
        self._normalizer.clear()
        self.executor.submit(
            self._emit_browser_messages_snapshot,
            reason='focus_switch_to_browser'
```

```python
def _run_api_loop(self):
    """API 独立线程循环（常驻，懒启动）"""
    logger.info("[API Loop] 线程已启动，等待激活...")

    while self.running:
        try:
            # 未激活时低频休眠
            if not self._api_active:
                time.sleep(1.0)
                continue

            # 首次激活时初始化
            if not self.api_source:
                self._init_api_source()
                if not self.api_source:
                    self._api_active = False
                    self.safe_emit_status("❌ API 源初始化失败")
                    time.sleep(5.0)
                    continue
                self.safe_emit_status("🤖 API 模式已激活")
                convs = self.api_source.get_conversations()
                self.sessions_signal.emit(convs if convs else [])

            # 检查待发送
            text = self._api_pending_text
            if text:
                self._api_pending_text = None
                self._handle_api_send(text)

        except Exception as e:
            logger.error("API循环异常: %s", e)
            traceback.print_exc()
            self.safe_emit_status(f"❌ API循环错误: {e}")
            time.sleep(2.0)

        time.sleep(0.3)
```

## 六、`switch_mode` 改造后的完整行为

### 6.1 用户点击切到 API

```text
1. UI: on_mode_switch("api")
2. UI: self.current_mode = "api"
3. UI: inner_stack.setCurrentIndex(1)  → 显示 API 消息区
4. UI: worker.switch_mode("api")
5. Worker: self.ui_focus = "api"
6. Worker: if not self._api_active → _init_api_source() → _api_active = True
7. Worker: sessions_signal.emit(convs)  → UI 刷新 API 对话列表
8. Worker: messages_signal.emit(msgs)   → UI 渲染 API 历史
9. 浏览器循环：不受影响，继续 0.3s 轮询
```

### 6.2 用户点击切回浏览器

```text
1. UI: on_mode_switch("browser")
2. UI: self.current_mode = "browser"
3. UI: inner_stack.setCurrentIndex(0)  → 显示浏览器消息区
4. UI: worker.switch_mode("browser")
5. Worker: self.ui_focus = "browser"
6. Worker: _emit_browser_messages_snapshot()  → 推送浏览器最新消息
7. API 循环：不受影响，继续运行（如果有流式回复仍在接收）
```

### 6.3 后台 API 对话完成时

```text
1. API 线程: _handle_api_send() 完成
2. API 线程: _update_ai_state("idle", source="api")
3. UI: ai_state_signal 收到 {source: "api", state: "idle"}
4. UI: 如果 current_mode == "api" → 更新状态栏
5. UI: 如果 current_mode == "browser" → 不更新状态栏（但可触发通知）
6. 通知服务: 如果窗口不在前台 → 播放提示音 + 窗口闪烁
```

## 二、新增文件

### 2.1 `app/core/runtime/conversation_runtime.py`

```python
from dataclasses import dataclass, field
import time

@dataclass
class ConversationRuntime:
    """每个活跃 API 对话的运行时状态"""
    conv_id: str
    project_root: str = ""
    streaming: bool = False
    round_state: str = "idle"  # idle | streaming | detecting_tools | running_tools | finalized
    input_draft: str = ""
    created_at: float = field(default_factory=time.time)
    last_active_at: float = field(default_factory=time.time)

    def is_busy(self) -> bool:
        return self.streaming or self.round_state not in ("idle", "finalized")

    def touch(self):
        self.last_active_at = time.time()
```

### 2.2 `app/core/runtime/runtime_pool.py`

```python
import threading
from typing import Optional
from app.core.runtime.conversation_runtime import ConversationRuntime

class RuntimePool:
    """管理多个并发会话运行时"""
    def __init__(self):
        self._runtimes: dict[str, ConversationRuntime] = {}
        self._lock = threading.RLock()

    def get_or_create(self, conv_id: str, project_root: str = "") -> ConversationRuntime:
        with self._lock:
            if conv_id not in self._runtimes:
                self._runtimes[conv_id] = ConversationRuntime(
                    conv_id=conv_id,
                    project_root=project_root,
                )
            rt = self._runtimes[conv_id]
            rt.touch()
            return rt
```

```python
import subprocess
import tempfile
import os
import time
from app.core.code_validator import CodeValidator
from app.core.logging import get_logger

logger = get_logger("app.core.local_executor")


class LocalExecutor:
    """本地 subprocess 代码执行器，替代 DockerManager"""

    def __init__(self, default_project_root=None):
        self._default_root = default_project_root

    def execute_code(
        self,
        code: str,
        timeout: int = 60,
        project_root: str = None,
        venv_path: str = None,
        skip_validation: bool = False,
    ) -> tuple[int, str]:
        cwd = project_root or self._default_root or os.getcwd()
        python = self._resolve_python(venv_path, cwd)

        # 静态安全检查（保留原有机制）
        if not skip_validation:
            is_safe, warnings, errors = CodeValidator.validate(code)
            if not is_safe:
                msg = CodeValidator.format_validation_result(warnings, errors)
                return 1, f"❌ 代码验证失败\n{msg}"

        # 写临时文件并执行
        try:
            with tempfile.NamedTemporaryFile(
                mode='w', suffix='.py', dir=cwd,
                prefix='_exec_', delete=False
            ) as f:
                f.write(code)
                temp_path = f.name

            start = time.time()
            proc = subprocess.run(
                [python, temp_path],
                cwd=cwd,
                capture_output=True,
                text=True,
                timeout=timeout,
            )
            elapsed = time.time() - start
            output = (proc.stdout or "") + (proc.stderr or "")

            # 输出截断保护（最大 50KB）
            if len(output) > 50000:
                output = output[:50000] + "\n... [输出已截断]"

            logger.info(f"[LocalExec] exit={proc.returncode} time={elapsed:.1f}s")
            return proc.returncode, output

        except subprocess.TimeoutExpired:
            return -1, f"⏱️ 执行超时 ({timeout}s)"
        except Exception as e:
            return -1, f"❌ 执行异常: {e}"
        finally:
            if os.path.exists(temp_path):
                os.unlink(temp_path)

    def _resolve_python(self, venv_path, cwd):
        """解析 Python 路径：优先 venv，其次项目内 .venv，最后系统 python"""
        if venv_path:
            return venv_path
        # 检测项目内 venv
        for venv_dir in ['.venv', 'venv', '.env']:
            candidate = os.path.join(cwd, venv_dir, 'Scripts', 'python.exe')
            if os.path.exists(candidate):
                return candidate
            candidate = os.path.join(cwd, venv_dir, 'bin', 'python')
            if os.path.exists(candidate):
                return candidate
        return 'python'
```

### 1.1 `app/core/services/file_lock_service.py`

```python
import threading
import os
import time
from app.core.logging import get_logger

logger = get_logger("app.core.services.file_lock_service")


class FileLockTimeout(Exception):
    pass


class FileLockService:
    """文件级读写锁，防止并发写入踩踏"""

    def __init__(self):
        self._locks: dict[str, threading.RLock] = {}
        self._meta_lock = threading.Lock()  # 保护 _locks 字典本身
        self._holders: dict[str, str] = {}  # path → conv_id（调试用）

    def acquire(self, path: str, conv_id: str = "", timeout: float = 30.0) -> bool:
        key = os.path.abspath(path)
        lock = self._get_or_create(key)
        acquired = lock.acquire(timeout=timeout)
        if acquired:
            self._holders[key] = conv_id
            logger.debug(f"[FileLock] 获取锁: {key} by {conv_id}")
        else:
            holder = self._holders.get(key, "unknown")
            logger.warning(f"[FileLock] 超时: {key}, 当前持有者: {holder}")
            raise FileLockTimeout(
                f"文件被占用: {os.path.basename(path)} (持有者: {holder})"
            )
        return acquired

    def release(self, path: str):
        key = os.path.abspath(path)
        lock = self._locks.get(key)
        if lock:
            self._holders.pop(key, None)
            try:
                lock.release()
            except RuntimeError:
                pass  # 未持有锁时 release 会 raise

    def _get_or_create(self, key: str) -> threading.RLock:
        with self._meta_lock:
            if key not in self._locks:
                self._locks[key] = threading.RLock()
            return self._locks[key]

    def is_locked(self, path: str) -> bool:
        key = os.path.abspath(path)
        lock = self._locks.get(key)
        if not lock:
            return False
        acquired = lock.acquire(blocking=False)
        if acquired:
            lock.release()
            return False
        return True
```

```python
        self.api_input_area.set_pending_attachments(attachments)
```

### 2.4 在切换对话时调用

```python
# on_api_session_clicked 中：
def on_api_session_clicked(self, conv_id):
    # 保存当前草稿
    self._save_current_draft()
    # 执行切换
    self.worker.api_switch_conversation(conv_id)
    # 恢复目标草稿
    self._restore_draft(conv_id)
```

```python
def _get_current_conv_id(self) -> str:
```

# 并发模式改造计划书

> **最后编辑时间**: 2026-05-28 12:46:51  
> **状态**: 规划中  
> **目标**: 将 Browser / API 双模式从硬切换改为并行运行

---

## 一、核心原则

```text
1. 浏览器主力不动：核心轮询、状态机、DOM 解析、AutoFix 一行不改
2. 浏览器常驻后台：切焦点不断流，后台持续轮询和处理
3. API 并发解耦：per-conversation 运行时，多路同时跑
4. 工具安全隔离：路由防火墙 + 输入防火墙，防止踩踏
5. 多项目支持：ProjectEnvironment 实例化 + 本地 subprocess
6. 用户感知：提示音 + 角标 + 会话活动动画 + 草稿保留
```

## 四、防火墙设计

### 4.1 工具路由防火墙

**目的**：防止浏览器和 API 的工具调用互相踩踏

```text
规则：
1. 每个工具调用必须携带 conversation_id + project_root
2. 文件写入操作按 (project_root + file_path) 加锁
3. 浏览器主力线路走原有成熟链路，不改
4. API 线路走轻量并发链路
5. 同一文件同一时刻只允许一个写入者
```

### 4.2 输入回流防火墙

**目的**：只有浏览器状态机的工具结果才能碰 Chrome 输入框

```text
规则：
1. 只有 conversation_id == "browser_main" 的工具结果才能触发 CDP 输入
2. API 模式的工具结果只回灌到内存历史，严禁触碰 Chrome
3. 浏览器状态机处于 TOOL_EXECUTING → RESULT_READY 时才允许灌入
4. 灌入期间加输入框聚焦锁，完成后立即释放
```

## 五、分阶段实施计划

### 阶段一：浏览器常驻 + API 独立线程（P0）

**目标**：两个循环并行运行，互不干扰

#### 改动清单

| 文件 | 改动内容 | 风险 |
|------|----------|------|
| `app/core/worker.py` run() | 启动两个循环而非二选一 | 低 |
| `app/core/worker.py` _run_browser_loop() | 删除 `if self.mode != "browser": 退出` | 低 |
| `app/core/worker_modules/worker_api_mode.py` _run_api_loop() | 删除 `if self.mode != "api": 退出` | 低 |
| `app/core/worker_modules/worker_api_mode.py` switch_mode() | 不再互斥切换，改为启动/唤醒 | 中 |
| `app/core/worker.py` __init__ | `self.mode` 改为 `self.ui_focus`（仅控制 UI 焦点） | 中 |

#### 实现方案

```text
def run(self):
    # 浏览器循环始终在主线程跑（保持原有行为）
    # API 循环在独立线程跑
    self._api_thread = threading.Thread(target=self._run_api_loop, daemon=True)
    self._api_thread.start()
    self._run_browser_loop()  # 主线程 = 浏览器轮询
```

#### 验证标准

- [ ] 启动后浏览器轮询正常工作
- [ ] 切到 API 模式后浏览器轮询不中断
- [ ] API 模式可以独立发送和接收流式回复
- [ ] 切回浏览器模式后，后台积累的消息立即上屏
- [ ] 两边同时跑工具不崩溃

#### LocalExecutor 设计

```text
class LocalExecutor:
    def execute_code(self, code, timeout=60, project_root=None, venv_path=None):
        1. CodeValidator 静态检查（保留原有安全机制）
        2. 写临时文件到 project_root
        3. 解析 venv 的 python 路径
        4. subprocess.run([python, temp_file], cwd=project_root, timeout=timeout)
        5. 返回 (exit_code, stdout + stderr)
        6. 清理临时文件
```

```

class NotificationService:
    def __init__(self, main_window):
        self._window = main_window
        self._sound = QSoundEffect()
        self._sound.setSource(QUrl.fromLocalFile("assets/sounds/task_done.wav"))
        self._enabled_sound = True
        self._enabled_flash = True
    
    def notify_task_completed(self, conv_id, task_type):
        # 只在窗口不在前台时提醒
        if self._window.isActiveWindow():
            return
        if self._enabled_sound:
            self._sound.play()
        if self._enabled_flash:
            QApplication.alert(self._window, 0)
```

_input_drafts = {}  # key = conv_id, value = {text, attachments, staging}

def _save_current_draft(self):
    conv_id = self._get_current_conv_id()
    self._input_drafts[conv_id] = {
        'text': self.api_input_area.input_box.toPlainText(),
        'staging': self.api_input_area.staging_area.toPlainText(),
        'attachments': list(self.api_input_area.pending_attachments),

def _restore_draft(self, conv_id):
    draft = self._input_drafts.get(conv_id, {})

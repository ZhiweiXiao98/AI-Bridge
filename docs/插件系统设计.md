# 面板插件系统设计文档

## 概述

面板插件系统是一个灵活的、可扩展的面板管理框架，允许开发者创建、加载和管理独立的面板插件。

## 插件生命周期

```
加载 → 初始化 → 启用 → 运行 → 禁用 → 卸载
  ↓      ↓      ↓     ↓     ↓      ↓
on_load on_enable create_panel 运行中 on_disable on_unload
```

### 生命周期方法

| 方法 | 时机 | 用途 |
|:---|:---|:---|
| `on_load()` | 插件加载时 | 初始化资源 |
| `on_enable()` | 插件启用时 | 启用功能 |
| `create_panel()` | 创建面板时 | 创建 UI |
| `on_panel_created()` | 面板创建后 | 初始化面板 |
| `on_panel_closed()` | 面板关闭时 | 清理资源 |
| `on_disable()` | 插件禁用时 | 禁用功能 |
| `on_unload()` | 插件卸载时 | 释放资源 |

## 插件元数据 (plugin.json)

```json
{
  "id": "example_panel",
  "name": "示例面板",
  "version": "1.0.0",
  "author": "Your Name",
  "description": "这是一个示例面板插件",
  "icon": "🎨",
  "entry": "plugin.py",
  "class": "ExamplePanelPlugin",
  "default_area": "right",
  "dependencies": [],
  "min_app_version": "1.0.0"
}
```

### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|:---|:---|:---:|:---|
| `id` | string | ✅ | 插件唯一标识 |
| `name` | string | ✅ | 插件显示名称 |
| `version` | string | ✅ | 插件版本 |
| `author` | string | ✅ | 插件作者 |
| `description` | string | ✅ | 插件描述 |
| `icon` | string | ✅ | 插件图标（emoji） |
| `entry` | string | ✅ | 入口文件 |
| `class` | string | ✅ | 插件类名 |
| `default_area` | string | ✅ | 默认停靠位置 |
| `dependencies` | array | ❌ | 依赖的插件 ID |
| `min_app_version` | string | ❌ | 最低应用版本 |

### 1. 错误处理

```python
def create_panel(self):
    try:
        panel = MyPanel()
        return panel
    except Exception as e:
        logger.error(f"创建面板失败: {e}")
        return None
```

### 2. 资源管理

```python
def on_unload(self):
    # 释放资源
    if self.timer:
        self.timer.stop()
    if self.thread:
        self.thread.quit()
```

### 3. 配置验证

```python
def load_config(self, config):
```

## 常见问题

### Q: 如何访问主应用？
A: 通过 `self.app_context` 或在 `on_panel_created` 中通过 `panel.parent()` 获取。

### Q: 如何与其他插件通信？
A: 通过信号/槽机制或共享的事件总线。

### Q: 如何处理插件依赖？
A: 在 `plugin.json` 中声明依赖，加载器会自动检查。

### Q: 如何调试插件？
A: 在 `on_load` 中添加日志，使用 Python 调试器。

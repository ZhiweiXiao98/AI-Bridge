## 维护

1. 功能变化先更新当前状态及对应使用说明；新证据追加日记。
2. 计划书保留阶段边界，顶部写清用途；勾选验收项需要相应证据。
3. 模块职责只在结构导航维护，规则只在对应协议维护，测试命令只在测试说明维护。
4. 日记超过约 300 行时轮换原文归档，并验证查询工具可发现新归档。
5. 修改入口后检查相对链接、代码路径和命令；使用绝对日期，测试结论写明执行范围。

# 沙盒环境优化文档

> 历史阶段记录（2026-09-05 整理）：以下原文用于追溯当时的设计、实现与验证；当前能力见[项目状态](当前项目状态.md)，当前测试命令见[测试说明](../tests/README.md)。

## 概述

本次优化大幅提升了 AI Bridge 沙盒环境的安全性、可靠性和可观测性。

## 核心改进

### 1. 超时控制
- 默认 60 秒超时
- 异步重启容器，超时后立即返回
- 友好的错误提示

### 2. 代码静态检查
- 使用 AST 分析检测危险操作
- 禁止 eval(), exec(), compile()
- 警告危险模块导入

### 3. 执行历史记录
- 持久化到 .sandbox_history.json
- 记录执行时间、代码、输出、状态
- 提供统计信息

### 4. 沙盒监控面板
- 实时统计信息
- 容器状态显示
- 执行历史表格
- 自动刷新（每 5 秒）

## 常见问题排查

### 运行日志面板为空

**原因**：服务端日志只发送给 admin 用户

**解决**：使用 admin 身份启动
- python boot_remote.py --admin

### 超时控制时间过长

**原因**：容器重启需要时间

**解决**：已优化为异步重启

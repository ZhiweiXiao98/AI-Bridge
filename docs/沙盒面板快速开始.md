# 🚀 沙盒监控面板快速启动指南

## 📋 面板功能概览

沙盒监控面板提供了对代码执行环境的全面监控，包括：

### 📊 统计信息卡片
- **总执行**：累计执行的代码块数量
- **成功**：成功执行的数量（绿色）
- **失败**：执行失败的数量（红色）
- **成功率**：成功执行的百分比（蓝色）
- **平均耗时**：每次执行的平均时间（灰色）

### 🐳 容器状态
- ✅ 运行中：Docker 容器正常运行
- ⏸️ 已停止：容器已停止
- ❌ 不可用：Docker 环境不可用

### 📜 执行历史
显示最近 10 条代码执行记录：
- 执行时间
- 状态（成功/失败）
- 耗时
- 代码预览（前 50 字符）
- 输出预览（前 50 字符）

## 🎯 使用方法

### 启动应用
1. 启动服务端：python server.py
2. 启动客户端：python boot_remote.py

### 查看面板
1. 应用启动后，在右侧停靠区域找到 "🐳 沙盒监控" 面板
2. 如果面板被隐藏，点击菜单栏 **视图 → 面板 → 沙盒监控**

### 刷新信息
- **自动刷新**：面板每 5 秒自动刷新一次
- **手动刷新**：点击容器状态区域的 "🔄 刷新" 按钮

### 清空历史
1. 点击执行历史区域的 "🗑️ 清空历史" 按钮
2. 确认对话框中点击 "是"
3. 历史记录将被清空，统计信息重置

## 🧪 测试沙盒功能

## 📊 监控指标说明

### 成功率
- **90% 以上**：正常，代码质量良好
- **70-90%**：需要注意，可能有较多错误代码
- **70% 以下**：异常，需要检查代码或环境

### 平均耗时
- **< 1s**：正常，简单计算和数据处理
- **1-5s**：正常，复杂计算或文件操作
- **> 5s**：需要注意，可能有性能问题

## 💡 最佳实践

1. **定期清空历史**：避免历史文件过大
2. **关注成功率**：低于 80% 时检查代码质量
3. **监控平均耗时**：发现性能问题
4. **查看失败记录**：快速定位问题代码

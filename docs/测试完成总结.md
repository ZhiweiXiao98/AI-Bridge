### 验证测试框架是否工作
```powershell
# 激活虚拟环境
& .\.venv\Scripts\Activate.ps1

# 运行测试
pytest tests/ -v

# 生成覆盖率报告
pytest --cov=app --cov-report=html --cov-report=term-missing

# 查看报告
start htmlcov/index.html
```

### 运行特定测试
```powershell
# 仅运行配置测试
pytest tests/test_config.py -v

# 仅运行某个测试类
pytest tests/test_config.py::TestConfigManagerBasic -v

# 仅运行某个测试函数
pytest tests/test_config.py::TestConfigManagerBasic::test_default_config_structure -v

# 显示打印输出
pytest tests/ -v -s
```

## 💡 关键决策

### 为什么选择 pytest?
1. **业界标准** — 大多数 Python 项目都用 pytest
2. **插件丰富** — pytest-cov, pytest-mock, pytest-asyncio 等
3. **语法简洁** — `def test_*` 而不是 `def test*`
4. **易于扩展** — Fixtures 和 Hooks 非常灵活

### 为什么配置管理是第一个测试?
1. **最简单** — 没有 GUI、网络、异步复杂性
2. **高价值** — 配置错误会导致整个系统崩溃
3. **完整示例** — 包含保存、加载、验证、参数化等多种测试模式

### 为什么 92% 不是 100%?
```python
# app/core/config.py 中未测试的行:
29: json.dump(data, f, ensure_ascii=False, indent=4)  # Windows 路径问题
30: except: pass  # 故意捕获所有异常

# 这些行在测试中难以触发，需要专门的集成测试
```

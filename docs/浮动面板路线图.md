# 浮动面板系统实现路线图

## 📋 项目概述

**目标**：实现类似 Adobe Photoshop 的浮动可定制化面板系统

**技术方案**：QDockWidget + 自定义增强

**开发周期**：约 11-16 小时

---

## 🎯 核心决策记录

### 1. 布局管理策略
- **方案**：混合模式（自动保存 + 支持多个预设）
- **默认布局**：从配置文件读取（可修改、替换、保存）
- **保底布局**：显示所有面板（防止布局崩坏）
- **配置文件位置**：待定（建议 config/workspace_default.json）

### 2. 面板功能规格

#### 沙盒监控面板（标准版）
- 当前执行的代码块
- 实时输出（stdout/stderr）
- 执行历史记录
- 进度条显示

#### AI 操作日志面板
- 类似 PS 历史记录窗口
- 支持多对话切换（标签页）
- 显示工具调用历史
- 时间戳和操作详情

#### 文件浏览器面板
- 从现有右侧栏改造
- 支持浮动和停靠

### 3. 主题和样式
- 跟随主窗口主题（统一风格）
- 使用现有 theme.py 系统

### 4. 性能优化
- 参考 Cursor/灵码的实现
- 大量日志时的处理策略（待研究）

## 🔧 技术架构

### 核心组件

#### 1. DockablePanel（基类）
位置：app/ui/components/dockable_panel.py

功能：
- 继承 QDockWidget
- 提供统一的面板接口
- 处理主题切换
- 提供面板配置接口

#### 2. PanelManager（管理器）
位置：app/ui/managers/panel_manager.py

功能：
- 注册和管理所有面板
- 保存和加载布局
- 管理工作区预设
- 处理面板显示/隐藏

#### 3. 具体面板
- SandboxMonitorPanel：沙盒监控
- AIActivityPanel：AI 日志
- FileExplorerPanel：文件浏览器（改造）

### 配置文件结构

config/workspace_default.json：
- 面板位置和大小
- 面板可见性
- 停靠状态
- 标签页组合

config/workspace_presets/：
- 用户自定义预设
- 预设名称和描述

# 发送消息后自动滚动置底功能

## 问题描述

浏览器 AI 对话页面更新后，发送消息后有概率不自动置底，导致：
- 发送键/停止键被隐藏
- 对话状态检测（AI 就绪/AI 正忙）失败
- 流水线无法触发，agent 循环中断

## 解决方案

采用**方案一：在发送消息后添加滚动操作**

### 实现步骤

1. **在 `interaction.py` 中添加 `scroll_to_bottom()` 方法**
   - 位置：第 450 行（`switch_to_chat_tab` 方法之前）
   - 功能：使用 JavaScript 将聊天容器滚动到底部
   - 使用 `SELECTORS["scroll_container_xpath"]` 定位滚动容器
   - 使用 `scrollTo({top: scrollHeight, behavior: 'smooth'})` 平滑滚动

2. **修改 `worker.py` 中的 `real_send_text` 分支**
   - 位置：第 290-294 行
   - 在 `send_message()` 之后添加：
     - `time.sleep(0.5)` - 等待消息上屏
     - `scroll_to_bottom()` - 滚动到底部

## 修改文件

- `app/core/driver/interaction.py` - 添加 `scroll_to_bottom()` 方法
- `app/core/worker.py` - 修改 `real_send_text` 任务执行逻辑

## 工作流程

```
1. 用户/Agent 触发发送消息
2. 调度器执行 real_send_text 任务
3. 调用 connector.send_message() 发送消息
4. 等待 0.5 秒（让消息上屏）
5. 调用 scroll_to_bottom() 滚动到底部
6. 发送键/停止键显示，状态检测正常
```

## 预期效果

- ✅ 每次发送消息后自动滚动到底部
- ✅ 发送键/停止键始终可见
- ✅ 对话状态检测准确
- ✅ 流水线正常触发
- ✅ Agent 循环不再中断

## 测试建议

1. 发送短消息，观察是否自动置底
2. 发送长消息（多行），观察是否自动置底
3. 连续发送多条消息，观察是否每次都置底
4. 观察 Agent 自动修复流程是否正常

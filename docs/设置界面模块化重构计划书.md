# 设置页结构与维护

> 复核日期：2026-09-26。设置页使用侧边导航和分区内容，入口为 `app/ui/settings_page.py`。

## 页面与分区

`SettingsPage` 使用 `SettingsNav` 和 `QStackedWidget` 切换分区。每个分区置于独立 `QScrollArea` 中，底部提供保存配置按钮。

| 分区 ID | 显示名称 | 实现文件（位于 `app/ui/components/settings/`） |
| --- | --- | --- |
| `basic` | 基础配置 | `settings_basic.py` |
| `api` | API 配置 | `settings_api.py` |
| `api_fallback` | Fallback | `settings_api_fallback.py` |
| `api_usage` | 对话配置 | `settings_api_usage.py` |
| `subagent` | Subagent | `settings_subagent.py` |
| `context` | 快照推送 | `settings_context.py` |
| `blacklist` | 黑名单 | `settings_blacklist.py` |

`settings_nav.py` 管理导航，`settings_styles.py` 提供样式，`settings_widgets.py` 提供输入控件、字段布局和开关。`knowledge_rules_card.py` 维护知识库规则卡片。`settings_daemon.py` 导出 `SettingsSubagentSection` 的别名。

## 配置与运行时

分区使用 `config_changed` 发送配置动作，SettingsPage 根据动作刷新 API 或 Subagent 运行时。模型和工具探测通过 Worker 接口执行，完成信号把结果送回 UI。

模型列表写回 API Profile；reasoning 控件使用模型能力解析结果。会话级模型、思考设置、上下文容量和项目切换位于聊天栏，配置入口与会话控制的具体职责见[当前项目状态](当前项目状态.md)。

## 样式与滚轮

主题变化由 `theme_manager.theme_changed` 通知，设置分区使用主题 Palette 和局部样式。`ScrollSafeComboBox`、`ScrollSafeSpinBox` 的 `wheelEvent()` 忽略滚轮事件，SettingsPage 也为分区安装 `ScrollSafeFilter`。

新增控件需要选用适合的输入类，并实测滚动与键盘交互；控件存在和过滤器安装本身不能证明完整页面已经通过验收。

## 维护步骤

1. 在 `app/ui/components/settings/` 中选择对应分区实现。
2. 新增分区时同时更新 `SECTIONS` 和 `_create_sections()` 的类映射。
3. 沿用 `config_changed` 动作分发及主题接口。
4. 核对保存、重载、模型探测和 RPC 返回的完整路径。
5. 为读写配置的测试使用隔离目录。

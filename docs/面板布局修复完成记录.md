## 🔍 问题诊断

### 现象
每次重启客户端不会记忆上次关闭时的面板布局状态。

### 根本原因

在 `panel_manager.py` 中有 **两个同名方法** `save_layout()`，后定义的方法覆盖了先定义的方法：

1. **第一个 save_layout(self, filename=None)** - 第 138 行
   - 保存新格式: `{"panels": {}, "icon_bar": {}}`
   - 有 filename 参数
   - 保存到 `config/panel_layout.json`
   - ❌ 被覆盖，永远不会被调用

2. **第二个 save_layout(self)** - 第 230 行
   - 调用 `get_layout()` 返回旧格式
   - 无参数
   - 保存到 `.config/panel_layout.json`
   - ✅ 实际被调用的方法

### 问题链

```
Python 方法覆盖
    ↓
main_window 调用 panel_manager.save_layout()
    ↓
实际调用第 230 行的方法
    ↓
get_layout() 返回旧格式
    ↓
保存旧格式到文件
    ↓
restore_layout() 检测到旧格式
    ↓
状态恢复不完整
```

### 修改 2: get_layout() 返回新格式

**文件**: `app/ui/managers/panel_manager.py`  
**位置**: 第 211 行  
**目的**: 统一使用新格式保存

```python
def get_layout(self):
    """获取当前布局配置（返回新格式字典）"""
    panels_data = {}
    
    for panel_id, panel in self.panels.items():
        panels_data[panel_id] = {
            "visible": panel.isVisible(),
            "floating": panel.isFloating(),
            "area": self.main_window.dockWidgetArea(panel).value if not panel.isFloating() else None,
            "geometry": {
                "x": panel.x(),
                "y": panel.y(),
                "width": panel.width(),
                "height": panel.height()
            },
            "state": "floating" if panel.isFloating() else "docked"
        }
    
    # 返回新格式
    return {
        "panels": panels_data,
        "icon_bar": {
            "visible": self.icon_bar.isVisible() if self.icon_bar else True,
            "icons": list(self.panels.keys()) if self.icon_bar else []
        }
    }
```

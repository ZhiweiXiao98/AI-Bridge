## 🎯 问题总结

### 原始问题
每次重启客户端不会记忆上次关闭时的面板布局状态。

### 根本原因
1. **第一层问题**：方法覆盖导致保存旧格式
2. **第二层问题**：恢复逻辑使用错误的数据源
3. **第三层问题**：手动保存几何信息不准确（核心问题）

---

## 🔧 三次修复历程

### 第一次修复：格式统一

**问题**：
- `panel_manager.py` 中有两个同名方法 `save_layout()`
- 后定义的方法覆盖了先定义的方法
- 保存的是旧格式，不是新格式

**修复**：
- 修改 `get_layout()` 返回新格式
- 修改 `restore_layout()` 添加格式检测

**结果**：
- ✅ 配置文件格式正确
- ❌ 布局恢复不完整

---

### 第二次修复：数据源修正

**问题**：
- `restore_dock_sizes()` 函数使用 `layout.items()`
- 遍历的是 `"panels"` 和 `"icon_bar"` 键
- 而不是实际的面板数据

**修复**：
- 将 `layout.items()` 改为 `panels_data.items()`

**结果**：
- ✅ 能恢复面板大小
- ❌ 位置和顺序不准确

---

### 第三次修复：Qt 原生机制（本次）

**问题**：
- 手动保存几何信息（x, y, width, height）不准确
- Qt 的布局引擎会重新计算位置
- 无法保存分隔条位置、面板顺序等细节

**修复**：
- 使用 Qt 的 `saveState()` 和 `restoreState()` 机制
- 保存完整的窗口状态（二进制数据）
- 使用 base64 编码存储

**结果**：
- ✅ 完整保存所有布局信息
- ✅ 准确恢复所有细节
- ✅ 使用 Qt 官方推荐方式

## 📝 修改详情

### 文件：app/ui/managers/panel_manager.py

#### 1. save_layout() 方法（第 240 行）

**修改前**：
```python
def save_layout(self):
    layout = self.get_layout()
    # 直接保存 layout
    with open(config_file, 'w') as f:
        json.dump(layout, f)
```

**修改后**：
```python
def save_layout(self):
    import base64
    layout = self.get_layout()
    
    # 保存 Qt 主窗口状态
    qt_state = self.main_window.saveState()
    layout["qt_state"] = base64.b64encode(qt_state).decode('utf-8')
    
    with open(config_file, 'w') as f:
        json.dump(layout, f)
```

#### 2. restore_layout() 方法（第 260 行）

**修改前**：
```python
def restore_layout(self, layout):
    # 格式检测
    if "panels" in layout:
        panels_data = layout["panels"]
    else:
        panels_data = layout
    
    # 手动恢复每个面板
    for panel_id, config in panels_data.items():
        # 恢复位置、大小、可见性...
```

**修改后**：
```python
def restore_layout(self, layout):
    import base64
    
    # 优先使用 Qt 状态恢复
    if "qt_state" in layout:
        try:
            qt_state = base64.b64decode(layout["qt_state"])
            self.main_window.restoreState(qt_state)
            
            # 恢复可见性
            if "panels" in layout:
                for panel_id, config in layout["panels"].items():
                    panel = self.panels.get(panel_id)
                    if panel:
                        panel.show() if config.get('visible') else panel.hide()
            
            return
        except Exception as e:
            print(f"⚠️ Qt 状态恢复失败，使用备用方案: {e}")
    
    # 备用方案：原有的手动恢复逻辑
    # ...
```

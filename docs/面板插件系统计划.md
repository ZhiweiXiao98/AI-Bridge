## 📊 项目概述

### 目标
实现类似 Adobe 系列软件的面板插件系统，让面板可以独立开发、动态加载，解决 main_window.py 臃肿问题。

### 当前问题
- ❌ 所有面板硬编码在 main_window.py 中
- ❌ 添加新面板需要修改核心代码
- ❌ main_window.py 过于臃肿（约 700+ 行）
- ❌ 面板无法独立开发和分发

### 预期效果
- ✅ 面板可以独立开发和分发
- ✅ 支持动态加载/卸载面板
- ✅ 插件和内置面板使用相同 API
- ✅ main_window.py 更加简洁（预计减少 200+ 行）
- ✅ 用户可以自定义面板

#### ✅ 任务 1.5：集成到 MainWindow
**文件**: `app/ui/main_window.py`

**修改内容**：
```python
# 在 __init__ 中添加
self.plugin_loader = PanelPluginLoader([
    'plugins/panels',
    'app/ui/components/panels'  # 内置面板也可以作为插件
])

# 在 init_panels 中
def init_panels(self):
    # 扫描插件
    plugins = self.plugin_loader.scan_plugins()
    
    # 加载启用的插件
    for plugin_info in plugins:
        if plugin_info.enabled:
            self.load_panel_plugin(plugin_info.id)
    
    # 恢复布局
    self.panel_manager.restore_layout()

def load_panel_plugin(self, plugin_id: str):
    plugin = self.plugin_loader.load_plugin(plugin_id)
    panel = plugin.create_panel()
    self.panel_manager.register_panel(panel)
    self.addDockWidget(plugin.default_area, panel)
```

**预计时间**: 2-3 小时

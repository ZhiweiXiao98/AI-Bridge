# Data-Bridge 项目结构导航

> 复核：2026-09-26。按现有代码路径和职责组织；功能完成度与运行验证边界见[当前项目状态](当前项目状态.md)。

## 启动与通信

| 位置 | 职责 |
| --- | --- |
| `server.py` | FastAPI + Qt 无界面服务，HTTP/WebSocket、RPC 分发和 Worker 生命周期 |
| `boot_remote.py` | PySide6 登录和桌面入口，支持 `--mode browser/api` |
| `start_server.py`、`start_client.py` | Tkinter 启动器、模式选择、进程与日志管理 |
| `app/core/remote_worker.py` | 桌面端 RPC、状态同步和带请求 ID 的响应等待 |
| `app/core/remote_protocol.py` | 服务端信号与客户端消息路由契约 |
| `app/core/worker.py` | 主调度；领域操作委托给 `worker_modules/` |

## 对话与工具

| 位置 | 职责 |
| --- | --- |
| `app/core/api_source.py` | API 会话、有效 Profile、工具循环和请求快照 |
| `app/core/llm_provider.py` | Provider 请求、普通/工具流式接口、正文与思考事件 |
| `app/core/api_mode_config.py` | API Profiles 与 fallback chain 配置 |
| `app/core/model_capabilities.py`、`app/core/provider_errors.py` | reasoning 能力归一化、Provider 错误分类 |
| `app/core/api/` | 流式事件、模型与流状态 |
| `app/core/conversation_store.py` | 对话 JSON、会话级模型覆盖、thinking segments 和最近请求快照 |
| `app/core/context_manager.py`、`app/core/context_compaction.py` | 上下文预算、记忆与压缩 |
| `app/core/prompt_runtime/`、`Prompt/` | 系统策略、Prompt 来源与 Skills 提示词组装 |
| `app/core/driver/`、`app/core/browser_sync/` | Chrome 驱动、DOM 提取和规范化消息存储 |
| `app/core/round_state/` | Browser 回合状态机 |
| `app/core/services/tool_router_service.py`、`app/core/tool_runtime/` | 工具意图解析、执行、结果投影与后续回合 |
| `app/core/skills/` | Skills 元数据、加载和管理；`core/` 为内置能力 |
| `app/core/skills/core/journal_search/` | 当前日记及日期归档的按需查询 |

## Worker 领域桥接

`app/core/worker_modules/` 中按操作主题查找：

| 模块 | 职责 |
| --- | --- |
| `worker_api_mode.py`、`worker_api_conversation.py`、`worker_api_stream.py` | API 生命周期、会话控制、流消费 |
| `upstream_events.py`、`upstream_consumer.py` | 上游事件契约及状态/UI 投影 |
| `worker_context_workspace.py` | 上下文面板 payload、请求快照、历史操作和手动压缩 |
| `worker_project_switch.py` | 服务端项目切换与项目资源刷新 |
| `worker_browser_message_sync.py`、`worker_browser_tool_input.py` | 浏览器消息同步与工具输入提取 |
| `worker_browser_commands.py`、`worker_browser_stateless.py` | 浏览器命令和无上下文 Profile |
| `worker_code_workspace.py`、`worker_runtime_monitor.py` | 代码暂存、文件工作台及工具队列监控 |
| `worker_skills.py`、`worker_test_runner.py` | Skills 管理和后台测试 |
| `worker_agent_sidecar.py`、`worker_subagent_bridge.py`、`worker_subagent_notify.py` | 侧车修复、后台建议桥接与回复完成通知 |

## UI、扩展和基础服务

| 位置 | 职责 |
| --- | --- |
| `app/ui/main_window.py` | 主窗口、面板注册和信号连接 |
| `app/ui/pages/chat/` | 聊天页面、消息区、输入区、API 会话列表和流式投影 |
| `app/ui/pages/chat/status_bar.py` | 会话级模型/思考控制、上下文容量和项目切换 |
| `app/ui/pages/chat/api_skill_references.py` | `/` Skills 建议和引用归一化 |
| `app/ui/components/chat.py`、`app/ui/components/chat_bubble_stream.py` | 历史消息和流式气泡，包括 thinking 段 |
| `app/ui/components/settings/` | API、fallback、上下文、知识库等设置分区 |
| `app/ui/components/panels/`、`app/ui/managers/`、`app/ui/plugins/` | 面板、布局和插件生命周期 |
| `plugins/panels/` | 示例面板与 Skills 面板；见[插件入口](../plugins/panels/README.md) |
| `app/core/project_context.py` | 当前项目、最近项目和项目资源路径 |
| `app/core/knowledge/`、`app/core/services/knowledge_service.py` | 检索、向量索引、重排、队列和健康状态 |
| `app/core/subagent/` | 后台建议、任务与模型路由 |
| `app/core/logging/`、`app/ui/logging/` | 结构化日志、噪声控制与 UI 日志桥接 |
| `app/core/docker_manager.py`、`app/core/sandbox/` | Docker 沙盒管理 |
| `mobile/` | 静态 Web/PWA 手机客户端，通过 HTTP/WebSocket 连接电脑服务；`serve_mobile.ps1` 提供本地页面服务 |
| `rhino/`、`rhino_plugin/`、`RhinoBIM_Client/` | Rhino 脚本、Python 插件及 C# 客户端 |
| `experimental/` | 实验服务与客户端 |

## 数据、脚本与文档

| 位置 | 用途 |
| --- | --- |
| `config/api_mode.example.json` | 可入库的 API 配置示例 |
| `config/api_mode.json`、`config.json`、`server_config.json` | 本机 API 与应用配置 |
| `config/conversations/` | API Source 显式使用的软件级对话目录；项目元数据记录在会话中。未指定目录的 ConversationStore 使用当前项目的 `conversations/` |
| `knowledge_bases/` | 以项目标识隔离的本地知识索引 |
| `projects.json`、`app_state.json`、`ignored_blocks.json`、`launcher_settings.json` | 最近项目、应用状态、忽略块和启动器本地状态 |
| `.config/`、`config/workspace_presets/` | 工作区布局、短语与预设 |
| `tools/`、`scripts/` | 索引、打包、诊断和维护脚本 |
| `tools/smart_update_structure.py` | 生成 `docs/PROJECT_STRUCTURE_DUMP.md` 辅助清单 |
| `tests/`、`pytest.ini`、`run_checks.ps1` | 测试与回归入口；见[测试说明](../tests/README.md) |
| `docs/` | 现役说明和标注了用途的阶段材料 |
| `docs/归档/`、`AI_JOURNAL.md` | 原文归档、标题索引和新记录 |

新增模块时补充对应职责；无需维护文件数量、私人配置值或重复的版本更新流水。
